# What this is
This is a scrap project for hands-on learning: a minimal Django backend (notes API) paired with a Vue frontend, built step by step.

The project is split into two sibling folders:
- `django-backend/` — Django project (originally a Django-only scrap project, now serving as the API backend)
- `vue-frontend/` — Vue single-page app that talks to the Django API
